# ЭХО РУИН — прототип игрового проекта

Браузерный 2D-платформер (HTML5 Canvas, чистый JavaScript, без сборки и без Unity).
Учебный проект для отчёта по производственной практике (кейс-задачи 3–5).

## Как запустить локально
1. Скачайте `index.html`.
2. Откройте его двойным щелчком в любом современном браузере (Chrome, Firefox, Edge).

## Управление
- `←`/`→` или `A`/`D` — движение
- `SPACE` / `W` / `↑` — прыжок (с coyote time и jump buffer)
- `SHIFT` / `X` — рывок (кадры неуязвимости, оглушает дронов)
- `E` / `Q` — эхо-импульс: открывает скрытые мосты и оглушает врагов в радиусе
- `R` — перезапуск уровня

## Механики
- Отзывчивое управление: coyote time (6 кадров) + jump buffer (6 кадров).
- Рывок с i-frames: 10 кадров, откат 60 кадров.
- Эхо-импульс: радиус 220 px, откат 90 кадров; скрытые мосты становятся
  твёрдыми на ~5 секунд, враги оглушаются на 200 кадров.
- Враги-дроны: патруль с проверкой обрыва, погоня при обнаружении.
- Шипы, 3 единицы здоровья, чекпоинты, финиш — Глубинное Ядро.
- Адаптивная сложность: каждая смерть повышает коэффициент врагов на 0.15
  (диапазон 0.8–1.5), 25 секунд без смертей снижают его на 0.05.

## Публикация на GitHub Pages (чтобы получить «ссылку на проект»)
1. Создайте публичный репозиторий, например `echo-of-ruins-practice`.
2. Загрузите в него файл `index.html` (через веб-интерфейс GitHub: Add file → Upload files → Commit).
3. Settings → Pages → Branch: выберите `main`, папку `/ (root)` → Save.
4. Через 1–2 минуты ссылка вида `https://ВАШ_ЛОГИН.github.io/echo-of-ruins-practice/`
   появится в разделе Actions/Deployments — она и будет ответом на кейс-задачи 3–5.
